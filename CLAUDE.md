# Kaiser's Slayers – Hinweise für KI-Assistenten

- Fabric-Mod für Minecraft 26.2 (Mojang-Namen, unobfuskiert, Loom `net.fabricmc.fabric-loom`), Java 25.
- Aufbau und Anleitung für neue Features: siehe `ENTWICKLUNG.md`.
- Reine Anzeige-Mod für Hypixel SkyBlock – niemals Automatisierung/Makros einbauen.
- Spielertexte (Menü, HUD, Alerts, Chat) auf Englisch mit SkyBlock-Fachbegriffen; Code-Kommentare und Doku auf Deutsch.
- Nach Änderungen: `./gradlew build` (läuft auch die JUnit-Tests); CI baut jeden Push.
